# Privacy Policy for Obsidian Highlight Clipper

**Effective date: July 16, 2026**

Obsidian Highlight Clipper is designed to help you highlight text on web pages and save selected highlights to Obsidian.

## Data the extension handles

The extension handles the following data only to provide its clipping functionality:

- Text you explicitly highlight on a web page.
- The URL of the page containing those highlights.
- Extension preferences, such as save location, source-link preference, language, sidebar theme, and highlight appearance.

## How data is used and stored

Highlights and page URLs are stored in Chrome session storage so they can be displayed in the side panel and saved when you choose to do so. This temporary clip queue is cleared when Chrome fully exits. Extension preferences may be stored using Chrome Sync when sync is enabled in your browser.

When you select **Save to Obsidian**, the extension sends the selected highlights and, if enabled, the source link to the Obsidian application installed on your device through an `obsidian://` link. This action occurs only after you explicitly click the save button.

## Data sharing

The extension does not collect, transmit, sell, rent, or share your data with external servers, advertisers, analytics providers, or other third parties. It makes no network requests to external services.

## Your choices

You can remove individual highlights or clear all highlights from the side panel. You can also remove the extension at any time through Chrome's extension settings.

## Security

The extension uses Chrome's built-in extension storage APIs. No user account, password, payment information, or browsing history is collected by the extension.
